# AI-фитнес-тренер — Telegram-бот (MVP)

Простой MVP по твоей стратегии: бот собирает данные пользователя, генерирует план тренировок
и питания через Claude API, отслеживает прогресс через обратную связь, напоминает о тренировках.
Модель доступа: бесплатный триал → промокод/подписка.

## Что уже есть

- `/start` — онбординг: цель, уровень, оборудование, дни в неделю, ограничения
- Генерация плана тренировок на неделю (Claude)
- `/meal` — план питания на день + список покупок на неделю
- `/feedback` — рассказать, как прошли тренировки → бот корректирует план
- `/remind` — ежедневное напоминание в 09:00
- `/status`, `/activate КОД` — управление триалом/подпиской
- Дисклеймер про отсутствие медицинских рекомендаций встроен в промпты и в приветствие

## Стек

- Node.js + [Telegraf](https://telegraf.js.org/) (Telegram Bot API)
- [`@anthropic-ai/sdk`](https://www.npmjs.com/package/@anthropic-ai/sdk) — генерация планов
- `node-cron` — ежедневные напоминания
- Хранилище: JSON-файл `data/users.json` (для MVP достаточно; при росте — заменить на БД)

Все файлы лежат в одной папке (без вложенных подпапок) — специально, чтобы было удобно загружать их на GitHub с телефона.

## Установка локально

```bash
npm install
cp .env.example .env
```

Заполни `.env`:
- `TELEGRAM_BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather)
- `ANTHROPIC_API_KEY` — из console.anthropic.com
- `ACCESS_CODES` — промокоды для ручной активации подписки (например `FIT2026`)
- `PAYMENT_LINK` — ссылка на оплату (Prodamus и т.п.), которую бот присылает после окончания триала

Запуск:

```bash
npm start
```

## Деплой на Railway (как у @neyrofabrika_bot)

1. Залей проект в GitHub-репозиторий.
2. На [railway.app](https://railway.app) → New Project → Deploy from GitHub repo.
3. В Variables добавь те же переменные, что в `.env`.
4. Railway сам подхватит `npm start` как команду запуска (см. `package.json`).
5. После деплоя открой бота в Telegram и проверь `/start`.

## Как проверить гипотезу (по твоей стратегии)

1. Дай доступ первым 10–20 подписчикам из блога (промокод из `ACCESS_CODES`).
2. Собери обратную связь через `/feedback` и личные сообщения.
3. Если люди реально пользуются и готовы платить после триала — переводи на платную подписку
   (`PAYMENT_LINK`), масштабируй контент вокруг кейса.

## Ограничения MVP / что можно улучшить дальше

- Хранилище — простой JSON-файл, не рассчитан на большую нагрузку — при росте перейти на Postgres/SQLite.
- PDF-экспорт плана и картинки/видео с техникой упражнений (YouTube-подбор) в этой версии не реализованы —
  осознанно оставлены на следующий этап, чтобы быстрее проверить спрос.
- Оплата подписки — через промокод вручную (как в @neyrofabrika_bot), без автоматической интеграции с Prodamus.
  Это можно добавить, когда появится подтверждённый спрос.
- Бот не должен использоваться при травмах/заболеваниях без консультации врача — это прописано в дисклеймере
  и в системных промптах для генерации планов.
